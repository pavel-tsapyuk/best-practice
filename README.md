# Codex Shared Memory

Общий пакет правил, принципов, инструментов и практических паттернов для всех Codex-сред пользователя.

## Как использовать

1. Помести содержимое этого репозитория в доступное Codex место или подключи репозиторий к рабочей среде.
2. В начале новой рабочей сессии попроси Codex прочитать корневой `AGENTS.md`.
3. `AGENTS.md` является обязательным набором правил по умолчанию.
4. Файлы в `memory/` используются как долговременная база знаний:
   - `PRINCIPLES.md` — архитектурные и рабочие принципы;
   - `TOOLS.md` — радар инструментов;
   - `PATTERNS.md` — переиспользуемые технические и бизнес-паттерны;
   - `PROJECT_APPLICATIONS.md` — применение к типовым задачам;
   - `SUPERPOWERS.md` — обязательное правило Using superpowers.
5. Проектный `AGENTS.md` конкретного репозитория имеет приоритет над общими рекомендациями, если правила конфликтуют.
6. Не считать этот пакет статичным: при появлении устойчиво полезных практик обновлять его осознанно, а не складировать каждую модную ссылку.

## Основная идея

Не строить «суперагента» там, где достаточно детерминированной автоматизации. Сначала формализовать задачу, критерии готовности, границы и проверки. Затем выбирать инструменты.
